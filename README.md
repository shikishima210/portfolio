# 杉島輝 ポートフォリオサイト

グラフィックデザイン × デジタルファブリケーションを軸にした、名古屋文理大学 情報メディア学科3年 杉島輝のポートフォリオ。

公開URL: https://shikishima210.github.io/portfolio/

## 中身
- `index.html` … サイト本体。画像もすべて埋め込み済みで、この1ファイルだけで動作します。

## ローカルで確認する
`index.html` をブラウザで開くだけです。ビルド作業は不要です。

## 更新のしかた
`index.html` を編集して push すると、GitHub Pages に自動で反映されます。

- 作品を足す … `const IMG` に画像(data URI)を追加し、`const W` に作品データを1件追加、`BASE_ORDER` に id を追加
- 絞り込みタブ … 各作品の `tags`(例: `平面物 / graphic / 個人制作`)を参照しています
- 連絡先 … CONTACT セクションのメール・Instagram・X のリンク

## 外部から読み込んでいるもの
- Three.js (cdnjs)
- Google Fonts (Archivo Black / Archivo / Zen Kaku Gothic New / Zen Kurenaido)
